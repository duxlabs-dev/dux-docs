# Dux Edit Installation

Dux Edit installs a single `dux-edit` binary with the UI embedded, a `dedit` alias, a desktop entry, AppStream metadata, an icon, and a polkit policy for saving files as administrator.

## Requirements

- dux-qt-base 0.4.3 or newer, Dux's build of [Quickshell](https://quickshell.org) that runs the UI: `dux-qt-base` on Arch, Fedora and Void, `libdux-qt-base0` on openSUSE, Debian, Ubuntu and PikaOS, from the [Dux repositories](../repo/index.mdx). Building with `QTBASE=1` embeds the runtime instead.
- Go 1.27+ (build from source only; the binary is pure Go with no cgo)

Optional:

| Package | Binary | Enables |
| --- | --- | --- |
| `hunspell` and a dictionary | `hunspell` | spellcheck |
| `polkit` | `pkexec` | saving root-owned files as administrator |
| `xdg-desktop-portal` | | the open and save dialogs |

## Distribution Packages

Each Dux repository ships two packages: `dux-edit` follows tagged releases, and `dux-edit-git` builds from upstream `master`. They conflict, so install one. Both pull in dux-qt-base automatically, and on most distributions they also recommend polkit and hunspell with an English dictionary.

### Arch Linux


```bash
paru -S dux-edit-bin        # or dux-edit-git for the latest development build
```


### Fedora & CentOS


```bash
sudo dnf copr enable duxlabs/dux-repo
sudo dnf install dux-edit        # or dux-edit-git for the latest development build
```

### Void Linux

Void carries only the stable `dux-edit` package.


```bash
echo "repository=https://void.duxlabs.dev/dux-repo/current" | sudo tee /etc/xbps.d/dux.conf
sudo xbps-install -Su
sudo xbps-install -S dux-edit
```


On the first sync, `xbps-install` shows the Dux Labs signing key fingerprint and asks you to trust it.

Distribution packages install `dux-edit` and the `dedit` alias to `/usr/bin`, plus the desktop entry, icon, AppStream metadata, polkit policy and shell completions.

## Release Binary

Each tagged release publishes `linux-amd64` and `linux-arm64` binaries with the UI embedded, plus a tarball of shell completions, on the [GitHub releases page](https://github.com/duxlabs-dev/dux-edit/releases).


```bash
curl -fsSLO https://github.com/duxlabs-dev/dux-edit/releases/latest/download/dux-edit-linux-amd64.tar.gz
tar -xzf dux-edit-linux-amd64.tar.gz
sudo install -Dm755 dux-edit-linux-amd64 /usr/local/bin/dux-edit
```


The release binary does not embed dux-qt-base, so install it first (see [Requirements](#requirements)). The desktop entry and polkit policy come from a distribution package or `make install`.

## Build from Source

```bash
git clone --recurse-submodules https://github.com/duxlabs-dev/dux-edit.git
cd dux-edit
make
sudo make install
```

`make` builds `core/bin/dux-edit` with the UI embedded. `make QTBASE=1` also builds dux-qt-base from the submodule and embeds it. `make install` puts these under `/usr/local` (change it with `PREFIX`, and stage with `DESTDIR`):

| File | Location |
| --- | --- |
| `dux-edit`, `dedit` | `$PREFIX/bin` |
| `dev.duxlabs.edit.desktop` | `$PREFIX/share/applications` |
| `dev.duxlabs.edit.svg` | `$PREFIX/share/icons/hicolor/scalable/apps` |
| `dev.duxlabs.edit.metainfo.xml` | `$PREFIX/share/metainfo` |
| `dev.duxlabs.edit.policy` | `/usr/share/polkit-1/actions` |

The polkit policy names the installed binary and pkexec refuses any other path, so reinstall it if you move the binary. `sudo make uninstall` removes everything.

### Try It Without Installing

```bash
make run
```

Builds without the embedded UI and loads `quickshell/` from the repo with hot reload.

## Run It

```bash
dux-edit                # show the window, starting the app first if needed
dux-edit run -d         # start in the background
```

Open it from your launcher, or bind a key. See [IPC](./ipc.mdx#keybinds) for compositor examples.

## Make It the Default Editor

The desktop entry registers Dux Edit for plain text, Markdown, JSON, XML, YAML, TOML, shell, and most source file types. Set it as the default for a type:

```bash
xdg-mime default dev.duxlabs.edit.desktop text/plain
xdg-mime default dev.duxlabs.edit.desktop text/markdown
```
