# Dux Edit

Dux Edit is a free, open-source text and document editor for Linux. It opens any text file without a project around it: notes, config files, scripts, Markdown. It sits between a scratchpad and an IDE, shares the look and feel of [Dux Modular Shell](https://github.com/duxlabs-dev/dux-shell), and follows its theme automatically. It takes over from the DMS notepad. `dux-edit` is the command name, and `dedit` is a short alias.

Built with [dux-qt-base](https://github.com/duxlabs-dev/dux-qt-base) and [Go](https://go.dev/). The core is pure Go with no cgo.

## Features

- **Tabs and Drafts**: Reorder tabs, reopen closed ones, and keep untitled drafts across restarts. Closing the window never loses work.
- **Crash Recovery**: Unsaved edits live in a swap file and come back after a crash or a restart.
- **Syntax Highlighting**: [Chroma](https://github.com/alecthomas/chroma) lexers, with colors derived from the desktop theme and editable per role.
- **Markdown Preview**: Side by side or preview only. Task boxes in the preview toggle the source line.
- **Spellcheck**: Uses `hunspell` and its dictionaries when installed. Code is checked in comments, and optionally in strings.
- **Find and Replace**: Regular expressions (RE2), whole word and case options, and replace all as one undo step.
- **Byte-for-Byte Editing**: Encodings, byte order marks and line endings are kept as they are. A save only differs from what was read where you edited, or converted.
- **Save as Administrator**: Root-owned files save through polkit, with a confined helper.
- **Line Commands**: Duplicate, delete, move, join and sort lines, and change case.
- **Simple and Advanced Modes**: Simple hides the status details, line numbers and a lone tab.
- **Plugins**: QML plugins with the same manifest format as DMS plugins. See [Plugins](plugins).
- **DMS Notes Import**: Copy your DMS notepad tabs and settings in one command.
- **Light on Resources**: Nothing polls and a hidden window holds no editors. See [Usage](usage#running-in-the-background).
- **Localized**: User-facing strings are translatable.
