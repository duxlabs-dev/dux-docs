# Keyboard

Open **Settings → Keyboard Shortcuts** (`Ctrl+,`) for this list with a search box. Plugin shortcuts are listed there too.

## Files

| Action | Keys |
| --- | --- |
| New document | `Ctrl+N`, `Ctrl+T` |
| Open files | `Ctrl+O` |
| Save | `Ctrl+S` |
| Save as | `Ctrl+Shift+S` |
| Quit | `Ctrl+Q` |

## Tabs

| Action | Keys |
| --- | --- |
| Close tab | `Ctrl+W`, `Ctrl+F4` |
| Reopen closed tab | `Ctrl+Shift+T` |
| Next tab | `Ctrl+Tab`, `Ctrl+PgDown` |
| Previous tab | `Ctrl+Shift+Tab`, `Ctrl+PgUp` |
| Move tab left | `Ctrl+Shift+PgUp` |
| Move tab right | `Ctrl+Shift+PgDown` |
| Go to tab 1 to 8 | `Alt+1` to `Alt+8` |
| Go to the last tab | `Alt+9` |

## Edit

| Action | Keys |
| --- | --- |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Shift+Z`, `Ctrl+Y` |
| Copy the whole document | `Ctrl+Shift+C` |
| Toggle overwrite mode | `Insert` |
| Go to the first character of the line, then its start | `Home` |

## Lines

| Action | Keys |
| --- | --- |
| Delete line | `Ctrl+D` |
| Duplicate line | `Ctrl+Alt+D`, `Ctrl+Shift+D` |
| Move lines up | `Alt+Up` |
| Move lines down | `Alt+Down` |
| Select line | `Ctrl+L` |
| Join lines | `Ctrl+J` |

Sort lines and the case commands (UPPERCASE, lowercase, Title Case) are in the window menu under **Lines and Case**. Line commands act on the selected lines, or on the current line.

## Find and Navigate

| Action | Keys |
| --- | --- |
| Find | `Ctrl+F` |
| Replace | `Ctrl+H` |
| Find next | `F3` |
| Find previous | `Shift+F3` |
| Go to line (`line` or `line:column`) | `Ctrl+G` |

## View

| Action | Keys |
| --- | --- |
| Toggle word wrap for this document | `Alt+W` |
| Cycle the Markdown preview | `Ctrl+P` |
| Full screen | `F11` |
| Zoom in | `Ctrl++`, `Ctrl+=` |
| Zoom out | `Ctrl+-` |
| Reset zoom | `Ctrl+0` |
| Settings | `Ctrl+,` |
