DMS edits NetworkManager's own connection profiles, so a change made in DMS also shows up in
`nmcli`, GNOME, and KDE, and the other way around.

:::note
The connection editor requires the NetworkManager backend. `iwd` and `systemd-networkd` keep
their existing pages. See [System Diagnostics](cli-doctor#network) for what each backend covers.
:::

## Connections

**Settings → Network → Connections** lists every saved profile, grouped into Ethernet, Wi-Fi,
VPN, Cellular, and Other, with active profiles first and the date each one was last used.
Selecting a profile opens the editor, as does **Edit** in a Wi-Fi network's menu or an Ethernet
adapter's options in Control Center. Each profile can be connected or disconnected from the
list, **Duplicate** copies it under a new name, and **Forget** deletes it. **Connect** is hidden
when the computer has no adapter for the profile's type.

**Add** asks for a **Type** (Ethernet, Wi-Fi, Cellular, or VPN) and, for VPN, the kind of VPN
(WireGuard, OpenVPN, or any installed plugin). Changing the type keeps the name. **Import**
adds a VPN profile from a file, as in [VPN](vpn#importing-a-profile). The hotspot has its own
group. Its row opens the [Hotspot](#hotspot) page when an adapter can host a hotspot, and
otherwise stays listed with **Forget**.

Every network page ends with an **All connections** card that opens this list, and the Network
overview has **Manage all connections** at the bottom.

A profile that NetworkManager keeps only in memory is marked as temporary and gets a
**Save permanently** button that writes it to disk. Saving any other edit leaves the profile
where it is already stored. When polkit doesn't allow the user to change a profile, the editor
opens read-only, and Duplicate and Forget are hidden.

Profiles the editor doesn't cover, such as VLAN, bond, bridge, DSL (PPPoE), CDMA, and team, stay
in the list marked **Not supported in Settings**. The button on their row opens them in
`nm-connection-editor`, or in `nmtui` in a terminal when only that is installed, and is hidden
when neither is.

## IPv4 and IPv6

| Setting | Effect |
| --- | --- |
| Method | Auto, Manual, Link-local, Shared (share this connection with other computers), or Disabled. IPv6 adds DHCP and Ignore. |
| DNS | Plain addresses, or `dns+udp://` and `dns+tls://` URLs with an optional port (IPv6 addresses in brackets). Either form can end in `#server-name`. |
| Automatic DNS, Automatic routes | Turned off, the DNS servers or routes that DHCP or router advertisements hand out are ignored. |
| Required | The connection fails when this IP version can't be configured. Off by default, so either version is enough. |
| Use only for resources on its network | The connection never gets the default route, so only traffic for its own network and routes uses it. |
| Privacy | IPv6 only. Enabled prefers temporary addresses for outgoing connections. |
| Address generation | IPv6 only. EUI-64 derives the address from the MAC address; Stable privacy keeps one address per network without exposing the MAC address. |

## Ethernet

| Setting | Options |
| --- | --- |
| Cloned MAC address | Default, Preserve (keep the current address), Permanent (the hardware address), Random (new on every connect), Stable (fixed per profile), or Manual. |
| Wake on LAN | Default, Disabled, Magic packet, or Ignore (leave the driver's setting). |
| Link negotiation | Ignore (leave the driver's setting), Auto, or Manual with a fixed speed and duplex. |

## Wi-Fi

| Setting | Options |
| --- | --- |
| Mode | Infrastructure (a client of an access point), Ad-hoc, or Hotspot. Channel is shown for the last two. |
| Band | Auto, 2.4 GHz, 5 GHz, or 6 GHz. |
| Power saving | Default, Enabled, Disabled, or Ignore (leave the driver's setting). |

Cloned MAC address takes the same options as on Ethernet.

## Security

Wi-Fi profiles choose Open, WPA/WPA2, WPA3, OWE, or Enterprise. A personal password is 8 to 63
characters, or a 64-digit hex key. Ethernet profiles have an **Enterprise** toggle for 802.1X.

Enterprise opens the 802.1X form:

| Field | Notes |
| --- | --- |
| Authentication | PEAP, TTLS, TLS, or PWD. PEAP and TTLS also ask for an inner authentication method and an optional anonymous identity. |
| Save password | Turned off, the password is asked for on every connect. |
| CA certificate | File, Use system certificates, or None. System certificates require a server name. None shows a warning: without a CA certificate the server isn't verified, and a fake network can capture the password. |
| Server | The name on the server's certificate. Exact must match it in full; Suffix also accepts any subdomain. |
| Client certificate, Private key | TLS only. A private key password is only needed for an encrypted key. |
| Advanced | PEAP version, Allow TLS 1.0 and 1.1, Disable TLS 1.3, and OpenSSL ciphers, for servers that fail with the defaults. |

### eduroam

**Import** in the header of **Settings → Network → Wi-Fi → Available networks** reads an
`.eap-config` file, which [eduroam CAT](https://cat.eduroam.org) provides for each
institution. The 802.1X form opens filled in, so only the username and password are left. A
username without a realm gets the institution's realm appended, and when the institution
requires its realm, a different one is refused.

DMS saves a profile for every network name in the file and connects to the one in range.
Certificates are stored in the profile, and NetworkManager keeps its own copy next to it, so
moving or deleting the downloaded file doesn't break the connection. Passpoint-only files are
not supported.

## Mobile broadband

| Setting | Notes |
| --- | --- |
| APN | Empty lets NetworkManager pick the APN for the network the modem registers on. |
| Allow roaming | Turned off, the connection doesn't start while roaming. |
| PIN | Left empty on a saved profile, the stored PIN is kept. |
| Network ID | The operator's MCC-MNC code, which locks the profile to that operator. |

The collapsed **PPP** section holds the options below:

| Option | Effect |
| --- | --- |
| Authentication | EAP, PAP, CHAP, MSCHAP, and MSCHAPv2. A method turned off is refused. |
| Use MPPE encryption | Requires encryption. Require 128-bit encryption and Stateful MPPE only apply with it. |
| BSD, Deflate, TCP header compression | On by default. |
| Send PPP echo packets | Checks the link every 30 seconds and drops it after 5 missed replies. |
| MTU, MRU | Empty uses the default. |

## Bluetooth

Bluetooth PAN and DUN profiles appear under Other and can be edited, but not created, here.
The device address and type are read-only. DUN profiles also get the mobile broadband and PPP
sections.

## Hotspot

**Settings → Network → Hotspot** appears when an adapter can host a hotspot. The
page sets the name, **Security** (Open, WPA2, or
WPA3), the band, then a channel for that band, **Hidden**, and the **IP address**
of the shared network as an address with a prefix from `/8` to `/30` (empty uses
NetworkManager's default, `10.42.x.1/24`). WPA3 only starts when the adapter supports it. The
page owns the hotspot profile. While a
hotspot with a password is running, **Show QR Code** displays a code that joins it, and
[`dms qr wifi`](cli-qr#wifi-qr-codes) works for it as well.

**Settings → Network → Wi-Fi** is hidden when the computer has no Wi-Fi adapter.

## Connectivity checking and captive portals

**Connectivity checking** in **Settings → Network → Status** turns NetworkManager's periodic
internet check on or off. The toggle only appears when NetworkManager has a check URL
configured. When the check finds a captive portal, the Status page and the Control Center show
**Log in to network**, which opens NetworkManager's check URL in the browser, where the portal
redirects to its login page. With checking off,
portals aren't detected.

## Behavior notes

- Disconnecting Ethernet no longer blocks the device. Only the disconnected profile stays down
  until it's connected again, so another profile on the same device can still autoconnect.
- **Preference** in **Settings → Network → Status** only sets route metrics: 100 for the
  preferred type and 300 for the others. Metrics the user set are left alone, and **Auto**
  restores NetworkManager's defaults.
- On NetworkManager older than 1.52, DNS servers must be plain addresses. URLs, ports, server
  names, and IPv6 scopes are refused on save.
