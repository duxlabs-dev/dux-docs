Dux Modular Shell will use the QT6 icon theme system as primary source for application icons. Depending on which platform theme you're using, icons are configured in different locations.

## How Icon Theming Works

Qt6 applications, including Dux Modular Shell, look for icon themes based on your `QT_QPA_PLATFORMTHEME` setting. Each platform theme reads icon configuration from a different location:

- **gtk3**: Reads from GTK settings (`~/.config/gtk-3.0/settings.ini`)
- **qt6ct**: Reads from qt6ct configuration (`~/.config/qt6ct/qt6ct.conf`)
- **kde**: Reads from KDE Plasma settings (`~/.config/kdeglobals`)

DMS leaves these files alone until you pick a theme under **Settings → Appearance → Icons**. Picking one writes it to GTK, qt5ct, qt6ct and KDE's `kdeglobals`, and saves the theme it replaced to `~/.config/gtk-3.0/icon-theme.dms-backup`. Choosing **System Default** puts that saved theme back, unless another tool changed the icon theme in the meantime.

KDE apps such as Dolphin read the icon theme once, when they start. Reopen them to see a new theme or new folder colors.

### Environment Variable Override

You can also set the icon theme directly using the `QS_ICON_THEME` environment variable:

```bash
export QS_ICON_THEME=Papirus-Dark
```

This takes precedence over platform theme settings and is useful for testing or when you want DMS to use a different icon theme than your other Qt applications.

## Icon Themes in DMS Settings

The **Icons** card under **Settings → Appearance** picks the icon theme, installs and removes themes, and can match a theme's folders to your colors.

### Picking a Theme

The **Theme** dropdown lists every installed theme with one of its icons. **Separate light and dark themes** gives light and dark mode a theme each.

**Manage themes** expands to the full list. Each theme shows a strip of its own icons (folders, file types, a few apps, the trash), so you can compare themes before picking one.

### Installing and Removing Themes

Under **Manage themes**, **Install a theme** takes an archive or a folder:

- **Archive** accepts `.tar.gz`, `.tar.xz`, `.tar.zst`, `.tar` and `.zip`. A `.tar.xz` archive needs the `xz` command.
- **Folder** accepts a theme folder, or a folder that holds several themes.
- Every folder with an `index.theme` is installed into `~/.local/share/icons`. Nothing from the archive is run, and no file is written outside the theme folders.
- A theme of the same name is replaced only after you confirm.

The delete button removes a theme from `~/.local/share/icons`. System themes under `/usr/share/icons` belong to your package manager and have no delete button. A theme that is in use, or that the theme in use inherits from, cannot be removed.

The same actions are available from a terminal. Each prints one line of JSON:

```bash
dms icon-theme list
dms icon-theme install ~/Downloads/Tela.tar.xz
dms icon-theme install --replace ~/Downloads/Tela.tar.xz
dms icon-theme remove Tela
```

`remove` does not know which theme your desktop uses. Pass `--in-use <theme>` for each theme that has to keep working, and the removal is refused if one of them inherits from the theme.

### Matching Folder Colors

**Match folder colors to theme** paints the picked theme's folders in your primary color and repaints them on every wallpaper or theme change. The rest of the theme is untouched.

DMS does this for:

- **Papirus**: `Papirus`, `Papirus-Dark`, `Papirus-Light` and the `ePapirus` themes
- **Breeze**: `breeze` and `breeze-dark`
- **Adwaita**
- **Tela**: the standard theme, its color variants and their light and dark forms
- **Colloid**: the standard theme, its color variants and schemes

The installed theme is never modified. DMS writes a small theme named `<Theme>-dms-<id>` into `~/.local/share/icons` that holds only the recolored folders and inherits everything else, and removes it when you switch the toggle off or pick another theme. For any other theme the toggle is disabled and says why. A plugin can add support for one, see [Icon Folder Recipes](./plugin-development.mdx#icon-folder-recipes).

### Dux Icons

[Dux Icons](https://github.com/duxlabs-dev/dux-icons) is an icon theme generated from your colors. It frames each app's own icon on a badge and draws folders and file types itself. It shows up in the **Theme** dropdown once the `dux-icons` command is installed. DMS rebuilds it on every wallpaper or theme change and when an app is installed or removed.

With Dux Icons picked, the card has three options in place of the folder toggle:

| Option | Does |
|--------|------|
| **Icon shape** | The badge outline: circle, squircle, rounded square, square, hexagon, cookie or clover |
| **Themed app icons** | Paints app icons in tones of your colors in place of their own |
| **Shaded icons** | Fills each badge with a soft gradient |

## Cursor Themes

The **Cursor** card under **Settings → Appearance** has its own **Manage themes** list. Each cursor theme is shown with its pointer.

- **Install a theme** takes an archive or a folder, in the same formats as an icon theme. Every folder with a `cursors` folder is installed into `~/.local/share/icons`. Nothing from the archive is run.
- A theme of the same name is replaced only after you confirm.
- The delete button removes a theme from `~/.local/share/icons`. System themes have no delete button. The cursor in use, or one it inherits from, cannot be removed.
- A pack that holds both icons and cursors is one folder, so removing it from either list removes both.

From a terminal:

```bash
dms cursor-theme install ~/Downloads/Bibata-Modern-Classic.tar.xz
dms cursor-theme install --replace ~/Downloads/Bibata-Modern-Classic.tar.xz
dms cursor-theme remove Bibata-Modern-Classic
```

`remove` takes `--in-use <theme>` the same way `dms icon-theme remove` does. `dms icon-theme list` also lists the installed cursor themes.

## GTK Platform Theme (gtk3)

If you're using the GTK passthrough method for Qt theming, icon themes are controlled via GTK settings.

### Configuration

Edit `~/.config/gtk-3.0/settings.ini`:

```ini title="~/.config/gtk-3.0/settings.ini"
[Settings]
gtk-icon-theme-name=Papirus-Dark
```

**Common icon themes:**
- `Papirus` / `Papirus-Dark`
- `Adwaita`
- `breeze` / `breeze-dark`
- `Tela`
- `Nordzy`

### Installing Icon Themes

```bash
# Arch - Papirus
sudo pacman -S papirus-icon-theme

# Arch - Adwaita (usually pre-installed)
sudo pacman -S adwaita-icon-theme

# Flatpak icon themes (available to all apps)
flatpak install flathub org.kde.PaplirusIconTheme
```

## Qt6ct Platform Theme

When using qt6ct for dedicated Qt control, icon themes are managed through the qt6ct interface or configuration file.

### Configuration via GUI

1. Launch `qt6ct` from your application launcher
2. Navigate to the **Icon Theme** tab
3. Select your preferred icon theme from the list
4. Click **Apply**

### Configuration via File

Edit `~/.config/qt6ct/qt6ct.conf`:

```ini title="~/.config/qt6ct/qt6ct.conf"
[Appearance]
icon_theme=Papirus-Dark
```

## KDE Platform Theme

If you're using KDE Plasma or the KDE platform theme, icon themes are managed through KDE's configuration system.

### Configuration via File

Edit `~/.config/kdeglobals`:

```ini title="~/.config/kdeglobals"
[Icons]
Theme=Papirus-Dark
```

## Installing Icon Themes

Icon themes can be installed system-wide or per-user.

### System-wide Installation

```bash
# Arch
sudo pacman -S papirus-icon-theme
sudo pacman -S breeze-icons
sudo pacman -S adwaita-icon-theme

# Fedora
sudo dnf install papirus-icon-theme
sudo dnf install breeze-icon-theme
sudo dnf install adwaita-icon-theme
```

### Per-user Installation

**Settings → Appearance → Icons → Manage themes** installs a downloaded archive for you, see [Installing and Removing Themes](#installing-and-removing-themes). By hand, extract the theme to `~/.local/share/icons/`:

```bash
# Example: Installing from a downloaded archive
mkdir -p ~/.local/share/icons
cd ~/.local/share/icons
tar xf ~/Downloads/Papirus-Dark.tar.gz
```

### Flatpak Icon Themes

Flatpak applications use icon themes from the Flatpak runtime:

```bash
# List available icon theme extensions
flatpak search icon

# Install Papirus for Flatpak apps
flatpak install flathub org.kde.PaplirusIconTheme
```

## Verifying Your Configuration

Check which platform theme you're currently using:

```bash
echo $QT_QPA_PLATFORMTHEME
```

:::tip[Dux Installer Users]

The Dux Installer only sets `QT_QPA_PLATFORMTHEME=gtk3` for non-systemd sessions, in the compositor config (niri's `environment` block, Hyprland's `hl.env`). With the default systemd setup it is not set; add it to a file in `~/.config/environment.d/` or override it per-service with `systemctl --user edit dms` (only affects DMS and apps it launches).

:::

:::note[Expose the variable to DMS]

This variable must be exposed to the `dms` process. Set it in the compositor config, a custom environment.d file, or via `systemctl --user edit dms` (only affects DMS and apps it launches).

:::

Check icon theme for each configuration:

```bash
# GTK configuration
cat ~/.config/gtk-3.0/settings.ini | grep icon-theme

# qt6ct configuration
cat ~/.config/qt6ct/qt6ct.conf | grep icon_theme

# KDE configuration
cat ~/.config/kdeglobals | grep -A 1 "\[Icons\]"
```

## Common Icon Theme Recommendations

### Material Design Style
- **Papirus** / **Papirus-Dark**: Most popular, excellent coverage
- **Tela**: Modern, colorful icons with good app coverage

### Gnome or KDE Style
- **Adwaita**: GNOME's default, clean and simple
- **breeze**: KDE's default, professional appearance

## Troubleshooting

### Icons not changing

Make sure you've restarted applications after changing icon themes. Qt applications cache icon information and need to be relaunched.

```bash
# Restart DMS to apply icon theme changes
dms restart
```

### Missing icons

Some applications might show missing icons if the theme doesn't include all required icons. Install a fallback theme:

```bash
# Arch
sudo pacman -S adwaita-icon-theme hicolor-icon-theme

# Fedora
sudo dnf install adwaita-icon-theme hicolor-icon-theme
```

### Wrong theme being used

Verify that your platform theme environment variable matches your configuration:

```bash
# Check current setting
echo $QT_QPA_PLATFORMTHEME
```

If you change `QT_QPA_PLATFORMTHEME`, you must restart your compositor session for the change to take effect.

### qt6ct shows no themes

If qt6ct shows an empty icon theme list, check that icon themes are installed in the correct location:

```bash
# Check system icon themes
ls /usr/share/icons/

# Check user icon themes
ls ~/.local/share/icons/
```

### Flatpak apps using different icons

Flatpak applications run in a sandboxed environment and may not see your system icon themes. Install icon themes via Flatpak:

```bash
flatpak install flathub org.kde.PaplirusIconTheme
```

## Platform Theme Comparison

| Feature | GTK3 | qt6ct | KDE |
|---------|------|-------|-----|
| **Configuration File** | `~/.config/gtk-3.0/settings.ini` | `~/.config/qt6ct/qt6ct.conf` | `~/.config/kdeglobals` |
| **GUI Tool** | GNOME Settings, nwg-look | `qt6ct` | System Settings |
| **Best For** | GTK-heavy desktops | Mixed Qt/GTK | KDE Plasma users |
| **Icon Cache** | GTK icon cache | Qt icon cache | KDE icon cache |
