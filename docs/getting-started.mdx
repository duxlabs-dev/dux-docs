Welcome to Dux! This guide will help you get started with installing and configuring the Dux suite on your system.

## Quick Installation

The fastest way to get started is with our one-line installer:

```bash
curl -fsSL https://install.duxlabs.dev | sh
```

This will:

- Install all dependencies for your distribution
- Set up Dux Modular Shell, dsearch, matugen, and other optional enrichments.
- Configure your chosen compositor (niri, Hyprland) and terminal (Ghostty, Kitty, Alacritty)

:::tip

The installer adds the appropriate repository (AUR, COPR, OBS, or PPA) for your distro—updates are managed through your normal package manager afterwards. On Fedora Atomic and bootc images, the installer does not change the system image: it prints the `rpm-ostree install` commands to run, and after you reboot and run it again it picks up with your earlier choices. See [Fedora Atomic & bootc images](duxinstall#fedora-atomic--bootc-images). If you install DMS directly from packages, run [`dms setup`](dms/cli-setup) to generate starter compositor and terminal configs (niri/Hyprland only). You can also deploy individual configs like `dms setup binds` or `dms setup colors`. Other compositors like sway, mangowm, labwc, and Miracle WM are supported—see [manual configuration](dms/installation#post-install).

:::
