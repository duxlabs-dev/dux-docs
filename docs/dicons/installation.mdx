# Dux Icons Installation

Dux Icons installs a single `dux-icons` command. Install it from the [Dux repositories](../repo/) or from source. Nothing else is needed, and the build itself never needs root.

## Requirements

- Python 3.9 or newer
- Tinted, Themed and Monochrome app icons and clipping of oversized artwork need Qt 6.7 or newer in Qt apps

## Distribution Packages

Dux Icons ships one package, `dux-icons`, which follows tagged releases. There is no `-git` build. It is a plain Python script, so the package is architecture independent and needs only `python3` and `hicolor-icon-theme`.

### Arch Linux


```bash
paru -S dux-icons
```


### Fedora & CentOS


```bash
sudo dnf copr enable duxlabs/dux-repo
sudo dnf install dux-icons
```

### Ubuntu

Ubuntu 26.04 LTS+ (Resolute Raccoon) is supported via Launchpad PPA.


```bash

sudo apt update
sudo apt install dux-icons
```

### Void Linux

Void carries the stable `dux-icons` package.


```bash
echo "repository=https://void.duxlabs.dev/dux-repo/current" | sudo tee /etc/xbps.d/dux.conf
sudo xbps-install -Su
sudo xbps-install -S dux-icons
```


On the first sync, `xbps-install` shows the Dux Labs signing key fingerprint and asks you to trust it.

Distribution packages install the `dux-icons` command to `/usr/bin`, and its data to `/usr/share/dux-icons`.

The package only installs the generator. Pick **Dux Icons** in DMS (see [With DMS](#with-dms)), or run `dux-icons` yourself (see [Without DMS](#without-dms)).

## Build from Source

```bash
git clone https://github.com/duxlabs-dev/dux-icons.git
cd dux-icons
make install
```

This installs the `dux-icons` command into `~/.local/bin`, and its data into `~/.local/share/dux-icons`. Make sure `~/.local/bin` is on your `PATH`. Set `PREFIX` to install somewhere else, and `DESTDIR` to stage. `make uninstall` removes both.

For development, `make link` links the command to your checkout instead of copying it.

## With DMS

DMS runs `dux-icons` when the command is on your `PATH`. Pick **Dux Icons** under **Settings → Appearance → Icons**. DMS builds the theme, and rebuilds it:

- on every wallpaper or theme change
- when an app is installed or removed
- when the shell starts

A rebuild is skipped when nothing it reads has changed.

The same card picks the look:

| Option | Does |
| --- | --- |
| **Icon shape** | Picks the tile outline, squircle by default |
| **App icon style** | **Color** keeps each app's own icon, **Tinted** repaints it in two tones of its tile, **Themed** (the default) and **Monochrome** draw every app as a one-color glyph on a theme-colored or near-gray tile |
| **Shaded icons** | Fills the tiles with a soft gradient |
| **Tile color** | With Color or Tinted, where each tile's color comes from: your theme, the app's icon, the icon's own background (**Edge Match**, the default) or a ring in the app's color |
| **Files & folders** | **Color** draws colored folders and file types, **Standard** puts them on the theme tile |

From a terminal:

```bash
dms ipc call settings set iconThemeDark dux-icons
dms ipc call settings set iconAppStyle themed
dms ipc call settings set iconShape squircle
dms ipc call settings set iconGradient true
```

See [Dux Icons in Icon Theming](../dms/icon-theming#dux-icons) for every option and its setting name.

## Without DMS

Give it the two colors:

```bash
dux-icons --tile '#9ecaff' --glyph '#003258'
```

This builds the theme into `~/.local/share/icons/dux-icons`. Desktops list it as **Dux Icons** in their icon theme setting. Run it again after installing or removing apps.
