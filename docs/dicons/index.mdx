# Dux Icons

Dux Icons is a generated icon theme that follows your colors. It puts each app's own icon on a Material tile, draws folders and file types itself, and paints all of it from your current Material colors. Change the wallpaper and the icons change with it.

It is built for [Dux Modular Shell](https://github.com/duxlabs-dev/dux-shell), and works on any freedesktop desktop.

It is a generator, not a hand-drawn app set. Your apps keep the artwork their authors shipped, and Dux Icons supplies the frame and the color.

## Features

- **Your Apps, One Shape**: Every installed app with a `.desktop` entry gets its own icon framed on the same tile. Nothing is redrawn, so a new app looks right the day you install it.
- **Follows Your Theme**: Tiles, folders and file types take Material `primary` and `on_primary`. With DMS they repaint on every wallpaper or theme change. Without DMS you pass the colors yourself.
- **Folders and File Types**: Folders, the home and XDG user folders, trash, network places and the common file types are drawn for the theme. They sit on the tile like your apps, or come as full-color folders with each file type in its own color.
- **Tiles in Each App's Color**: With DMS, a tile can take its color from the app's icon, match the background the icon is drawn on so the logo fills the tile, or ring a neutral tile in the app's color.
- **Seven Tile Shapes**: Circle, squircle, rounded, square, hexagon, cookie and clover, flat or with a soft gradient.
- **Four App Icon Styles**: Keep each app's own colors (Color), repaint them in two tones of the tile (Tinted), or draw every app as a one-color glyph on a tile in your theme color (Themed) or in near-gray (Monochrome). Glyphs come from the app's own symbolic icon where it ships one, a symbolic icon from an installed theme such as Papirus, or a cut-out of the app's logo.
- **A Normal Icon Theme**: The output is a standard freedesktop theme of scalable SVGs. GTK, Qt and KDE apps can all use it, and any name it does not provide falls back to `hicolor`.
- **Safe Builds**: Each run replaces the previous theme in one step, so nothing is ever half written. The build only writes to a directory it created itself.

## Documentation

- [Installation](installation) - Install the `dux-icons` command, with or without DMS
- [Usage](usage) - Commands, options, tile shapes and how the build works

To match the folders of other icon themes (Papirus, Breeze, Adwaita, Tela, Colloid) to your colors, see [Icon Theming](../dms/icon-theming) in the DMS docs. That is a DMS feature and does not need Dux Icons.
