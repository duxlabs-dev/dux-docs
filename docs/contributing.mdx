## How to Contribute

### Reporting Issues

Found a bug or have a feature request? Please open an issue on the relevant repository:

- [Dux Shell Issues](https://github.com/duxlabs-dev/dux-shell/issues)
- [Dux GOP Issues](https://github.com/duxlabs-dev/dux-gop/issues)
- [Dux Search Issues](https://github.com/duxlabs-dev/dux-search/issues)
- [Dux Greeter Issues](https://github.com/duxlabs-dev/dux-greeter/issues)
- [Dux Calendar Issues](https://github.com/duxlabs-dev/dux-calendar/issues)
- [Dux Files Issues](https://github.com/duxlabs-dev/dux-files/issues)

### Pull Requests

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Make your changes
4. Test thoroughly
5. Commit with clear messages: `git commit -m "<component/area>: new feature description"`
6. Push to your fork: `git push origin feature/my-feature`
7. Open a Pull Request

### Code Style

- **Go**: Follow standard Go formatting (`go fmt`, `make fmt`)
  - Include appropriate test coverage
  - Fix lint errors `golangci-lint run`
- **TypeScript/JavaScript**: Use consistent formatting
- **Documentation**: Use clear, concise language

For editor setup and detailed instructions, see the `CONTRIBUTING.md` file in the repository root.

### Translating
- Translations are managed through POEditor:
  - [Dux Shell](https://poeditor.com/join/project/kyeCPTpmJM)
  - [Dux Plugins](https://poeditor.com/join/project/72pNP8vhu5)
  - [Dux Calendar](https://poeditor.com/join/project/YQpBHiU50h)
  - [Dux Files](https://poeditor.com/join/project/L7zGgnX6DM)
- Collaborate with other translators of the same language using POEditor discussion/comment features
- Translation updates are posted in the `#dms-translations` channel on Discord. A dedicated role is pinged whenever new or changed terms need to be translated. To join the translation role, ping `@bbedward` in the [Niri Discord server](https://discord.gg/ppWTpKmPgT), where the Dux community currently lives.


## Community Guidelines

Be respectful on all forums such as GitHub discussions, discord, etc.

- Be respectful and inclusive
- Help others when you can
- Document your code
- Keep discussions on-topic
